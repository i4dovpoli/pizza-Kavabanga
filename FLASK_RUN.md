# Запуск через Flask

1. Встановити залежності:

```powershell
C:\Users\Redmi\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe -m pip install -r requirements.txt
```

2. Запустити сайт:

```powershell
.\start-flask.ps1
```

3. Відкрити:

```text
http://127.0.0.1:5000
```

Замовлення і коди самовивозу зберігаються у `server/data.sqlite`.
